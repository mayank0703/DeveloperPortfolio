System hardware profile documented using `lscpu`, `free -h`, `lsblk`, and `uname -a`. Includes a manual binary conversion walkthrough and command output logs.

- [System Profile](Linux/system_profile.md)
- [Command Outputs](Linux/commands_output.txt)

### 2. Shell Scripting & Automation (CO2)
Two Bash scripts automating developer tasks — a system information reporter and a folder backup utility.

- [sysinfo.sh](ShellScripts/sysinfo.sh) — System information report generator
- [backup.sh](ShellScripts/backup.sh) — Compressed folder backup with logging
