## 🗓️ Semester 1 (Current) — Foundation & Developer Tools

### Skills Learned
- **Linux Fundamentals:** Navigating the terminal, file permissions, process management, disk and memory profiling using commands like `ls`, `ps`, `df`, `free`, `lscpu`, and `lsblk`.

- **Git & GitHub:** Version control workflow — `init`, `add`, `commit`, `push`, `branch`, repository management, `.gitignore`, and Conventional Commits.
- **REST APIs & JSON:** Fetching data from public APIs using `curl`, parsing and filtering JSON with `jq`.
- **Python (Basics):** Variables, data types, loops, conditionals, functions.
- **HTML & CSS (Basics):** Building simple static web pages, structuring content, basic styling.
- **Markdown:** Technical documentation, README files, tables, and formatted reports.

## 🗓️ Semester 2 — Core Computer Science & Web Development

### Planned Topics
- **Data Structures & Algorithms:** Arrays, linked lists, stacks, queues, trees, sorting and searching algorithms, time complexity analysis (Big-O).
- **Database Management Systems:** Relational databases, SQL queries (SELECT, JOIN, GROUP BY), ER modelling, normalisation basics, hands-on with MySQL/PostgreSQL.
- **Web Development Basics:** Building dynamic web pages with HTML, CSS, JavaScript; introduction to frontend frameworks; understanding client-server architecture.
- **Object-Oriented Programming (OOP):** Classes, objects, inheritance, polymorphism, encapsulation — practised in Python and/or Java.

## 🗓️ Semester 3 Onwards — AI/ML Specialisation Track

### Chosen Track: **Artificial Intelligence & Machine Learning**

### Semester 3–4: Core AI/ML Foundations
- **Mathematics for ML:** Linear algebra, probability & statistics, calculus (gradients, optimisation).
- **Machine Learning:** Supervised learning (regression, classification), unsupervised learning (clustering, dimensionality reduction), model evaluation, scikit-learn.
- **Deep Learning Fundamentals:** Neural networks, backpropagation, CNNs, RNNs; hands-on with TensorFlow/Keras or PyTorch.
- **Data Analysis & Visualisation:** Pandas, NumPy, Matplotlib, Seaborn; exploratory data analysis on real datasets.

### Semester 5–6: Advanced & Applied AI
- **Natural Language Processing (NLP):** Tokenisation, embeddings, transformers, sentiment analysis, chatbot development.
- **Computer Vision:** Image classification, object detection, transfer learning, OpenCV.
- **MLOps & Deployment:** Model versioning (MLflow), containerisation (Docker), deploying ML models as APIs (Flask/FastAPI), cloud deployment (AWS/GCP).
- **Capstone Project:** End-to-end ML project — from data collection and preprocessing to model training, evaluation, and deployment.

### Semester 7–8: Industry Readiness
- **Internship:** Apply for AI/ML internship roles at tech companies or research labs.
- **Research / Thesis:** Explore a research topic in AI (reinforcement learning, generative AI, or domain-specific applications like healthcare or finance).
- **Open Source Contributions:** Contribute to popular AI/ML open-source projects (Hugging Face, TensorFlow, scikit-learn).
- **Portfolio Expansion:** Build 3–5 polished ML projects on GitHub with clear documentation and deployed demos.
